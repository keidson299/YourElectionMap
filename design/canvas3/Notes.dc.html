Two finals — the layout you liked, the map you wanted

Both finals take direction 1's page — card on the left, map running full-bleed behind it — and swap in direction 2's survey-instrument map: hairline district outlines on a coordinate grid, no filled shapes, hatching and a crosshair on the district you land in. The veil is now a partial gradient instead of a solid wash, so the grid and the boundaries stay readable all the way to the card's edge. Headline, tagline and field are all a step smaller.

The result page

Same shell in both finals: a 68px header keeping the address editable, a 400px rail listing every district that covers the address, and the map taking the rest. The rail's selected row is the boundary drawn solid on the map; the two overlapping districts are drawn dashed and dotted, keyed in the legend. Everything that isn't a map — next election date, candidate count, ballot measures — sits demoted at the foot of the rail behind one link.

Sample data

Every name, number and boundary on the result boards is invented — 1420 Maple Street, Springfield, Greenlake County, State House 44, the 14 candidates. Nothing is a real lookup, and the shapes are hand-drawn polygons, not real district geometry.

Decided at design time
  • Hidden <label> on every field; submit through a <form> so Enter works.
  • Line style, not colour alone, distinguishes the three boundaries — it survives a greyscale print and colour-blind vision.
  • Every colour is a :root token overridden for dark, never defined only in a media query.
  • Controls are 50px+; 40px in the result header, still over the 44px target with padding.
Building this
  • Plain CSS throughout — no library needed for either final.
  • With Chakra UI: field → InputGroup, primary → Button, rail rows → List + Badge, palettes → a theme token set. The SVG map stays hand-written either way.
  • Real boundaries later mean real geometry — the SVG here is a stand-in for whatever shapes the districts API returns.
  • Webfonts need one Google Fonts link; say so and I'll refit to system fonts.
